# 트러블슈팅 일지 - 2~4주차

## 문제 1. CSS 파일이 적용이 안 됨

**오류 상황**  
style.css 파일을 만들었는데 브라우저에서 스타일이 하나도 적용되지 않았음

**원인**  
index.html에서 CSS 파일을 연결하는 `<link>` 태그를 작성하지 않았음

**시도한 해결 방법**  
파일 이름이 틀렸나 확인해봄..

**최종 해결 방법**  
`<head>` 안에 `<link rel="stylesheet" href="style.css">` 추가하여 해결

## 문제 2. 버튼을 눌러도 아무 반응이 없음

**오류 상황**  
추가 버튼을 클릭해도 카드가 생기지 않았음

**원인**  
`script.js` 파일을 HTML에 연결하지 않아서 JavaScript가 실행되지 않았음

**시도한 해결 방법**  
코드가 잘못됐나 여러 번 확인함..

**최종 해결 방법**  
`<body>` 맨 아래에 `<script src="script.js"></script>` 추가하여 해결

---

## 문제 3. API 버튼을 눌렀을 때 데이터가 바로 안 나옴

**오류 상황**  
`fetch()`로 데이터를 받아오려 했는데 `console.log`에 데이터 대신 이상한 값이 찍힘

**원인**  
`fetch()`는 데이터를 바로 주는 게 아니라 기다려야 하는 비동기 함수인데, 기다리지 않고 바로 사용하려 했음

**시도한 해결 방법**  
`.then()`을 붙여봤지만 코드가 복잡해짐..

**최종 해결 방법**  
함수 앞에 `async`, 기다리는 줄 앞에 `await`를 붙이는 방식으로 변경하여 해결
