2~4주차 과제 트러블슈팅 및 개발 과정

2주차부터 4주차 과제를 진행하면서 HTML, CSS, JavaScript를 활용한 웹 페이지 구현 과정에서 많은 어려움을 겪었다.
처음에는 DOM 조작, 이벤트 처리, Grid 레이아웃, 비동기 통신(fetch) 등의 개념이 익숙하지 않아 기능 구현이 쉽지 않았다.

특히 JavaScript를 이용해 카드 데이터를 추가·삭제하고, 화면을 다시 렌더링하는 과정에서 코드의 흐름을 이해하는 데 시간이 오래 걸렸다.
또한 필터 기능이나 폼 제출 이벤트 처리 과정에서 페이지가 새로고침되거나, 데이터는 변경되었는데 화면에는 반영되지 않는 문제도 발생했다.

4주차에서는 외부 API 데이터를 불러오는 기능을 구현하면서 비동기 처리와 fetch() 사용 방법에 어려움을 느꼈다.
랜덤 유저 데이터를 추가했는데 화면이 갱신되지 않거나, 요청 중 버튼 중복 클릭으로 데이터가 여러 번 추가되는 문제도 있었다.

이번 과제는 혼자 해결하기 어려운 부분이 많아 AI의 도움을 받아 코드를 작성했다.
하지만 단순히 복사해서 사용하는 것이 아니라, AI가 작성한 코드를 직접 수정하고 실행 결과를 확인하면서 각 코드의 역할과 동작 원리를 이해하려고 노력했다.

예를 들어:

render() 함수가 데이터를 기반으로 화면을 다시 출력한다는 점
filter()를 이용해 원하는 데이터만 표시할 수 있다는 점
fetch()와 async/await를 사용해 외부 데이터를 비동기로 가져온다는 점
preventDefault()로 form의 기본 새로고침 동작을 막을 수 있다는 점

등을 직접 테스트하며 학습했다.

또한 CSS Grid와 media query를 사용해 반응형 레이아웃을 구현하면서 화면 크기에 따라 UI가 달라지는 방식도 익힐 수 있었다.

이번 과제를 통해 단순히 결과물을 만드는 것뿐 아니라, 코드를 읽고 수정하며 동작 원리를 이해하는 과정이 중요하다는 점을 배울 수 있었다.
